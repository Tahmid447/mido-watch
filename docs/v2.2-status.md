# Mido Watch V2.2 — implementation and verification

14 November 2026 (Japan). Continued from existing draft PR #1, branch `codex/mido-watch-v2`, baseline `756a757`. The old Mac checkout was absent, so the existing branch was cloned into its original path; the application was not rebuilt or its backend replaced.

## Implemented

- **Watch Audit**: private visual collection view, search, confirmation/status/priority/theme filters, source artwork and trailers, personal ratings, recommendation reasons/caveats, Japan provider attribution and independent season controls. Unsure sets a confirmation flag while preserving the current verdict. Explicit changes require a matching journal timestamp.
- **30-Day Plan**: an owner-protected ninth table, four week slots, ordered backups, completed/postponed states, reorder across weeks, start/complete, reschedule, remove from plan and replace from recommendations. A plan season action updates only that season’s journal. Existing ratings, notes, rankings and completion dates are retained. Plan/journal writes commit atomically; per-owner locks serialize reorder operations.
- **Tonight**: a transparent rules engine using time, format, mood, intensity, unfinished titles/seasons, preferences, known negative evidence and regional provider data. Shows reasons, caveats and optional weight contributions; does not claim machine learning. Unknown runtime/provider facts remain unknown. Acronym matching avoids false police/intelligence themes from words such as “social” or “accidental.”
- **Friendly ChatGPT updates**: Copy Context and file download, visual status-first guidance, optional structured-shortlist wizard, and raw JSON/full backups under collapsed Advanced. Context includes audit flags and a compact plan; backup restores match title identity rather than transfer owner UUIDs. Existing plans survive reimport.
- **Review groups**: audience ratings, professional critics, individual reviewer opinions and other evidence are distinct. Named reviewers support manual category, dated source/video URL and short summary without inventing a score or opinion. Empty groups are omitted and incompatible scores are never averaged.
- **Security patches**: pinned Next.js 16.4.6 and Zod 4.6.7 after current dependency advisories; production audit reports no known vulnerabilities.

## Database migration

`20261114112531_watch_audit_and_private_plan.sql` is version controlled and passes real PostgreSQL/PGlite tests. It adds confirmation flags/timestamps to watch/season journals, review categories, the private plan table, authenticated invoker audit/plan RPCs, and backward-compatible backup handling. Existing RLS policies are preserved; the new table has owner predicates in both USING and WITH CHECK and composite owner/title/season foreign keys. Functions have empty search paths and authenticated-only execution. No actual owner history, taste values or plan ordering is seeded in the public migration.

The migration was applied to the original hosted project through its authenticated Management API. Its timestamp matches the hosted migration ledger. Public TypeScript types were regenerated from the hosted schema; server actions omit absent optional RPC arguments to match those generated types. All nine user tables retain RLS.
